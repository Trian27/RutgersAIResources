## AI coding assistants

| Tool | Cost for students | Notes |
|:-----|:------------------|:------|
| [GitHub Copilot](https://docs.github.com/en/copilot) | Free with Copilot Student (see [Student offers](student-offers.md)). Anyone can use Copilot Free, which has a monthly limit. | Built into VS Code, with chat, inline suggestions, and an agent that can edit files and run commands. Also works in JetBrains IDEs, Visual Studio, and on github.com. See the [Copilot tutorial](tutorials/github-copilot.md). |
| [Microsoft Copilot Chat](https://it.rutgers.edu/ai/microsoft-copilot/) | Free with your Rutgers account | A general chat assistant. Good for explaining errors, concepts, and short snippets. It doesn't connect to your editor. |
| [Cursor](https://cursor.com/) | Free plan. The [student page](https://cursor.com/students) mentions occasional event promotions. | VS Code-based editor built around an AI agent. |
| [JetBrains AI](https://www.jetbrains.com/help/ai-assistant/about-ai-assistant.html) | Limited trial included in the [JetBrains Student Pack](https://www.jetbrains.com/academy/student-pack/) | AI Assistant and the Junie agent inside PyCharm, IntelliJ IDEA, and other JetBrains IDEs. |

### Getting more out of a coding assistant

- Ask it to explain code before you ask it to write code. You learn more, and you'll catch its mistakes faster.
- Give it context: the error message, the file, and what you expected to happen.
- Read and run everything it writes. Assistants confidently produce code that compiles but is wrong, insecure, or uses packages that don't exist.
- Never paste passwords, API keys, or other people's code or data into a prompt.

## Free GPUs and notebooks

| Platform | What's free | Limits |
|:---------|:------------|:-------|
| [Google Colab](https://colab.research.google.com/) | Jupyter notebooks in the browser, with occasional free GPU access | GPU access on the free tier is "heavily restricted" and not guaranteed. Google doesn't publish exact limits ([FAQ](https://research.google.com/colaboratory/faq.html)). |
| [Kaggle Notebooks](https://www.kaggle.com/code) | Notebooks with free GPUs and TPUs, plus thousands of public datasets | A weekly GPU quota that varies with demand ([docs](https://www.kaggle.com/docs/notebooks)) |
| [Hugging Face](https://huggingface.co/) | Open models, datasets, and free CPU [Spaces](https://huggingface.co/spaces) for hosting demos | Free accounts get limited GPU time ([pricing](https://huggingface.co/pricing)) |
| [Amarel](https://it.rutgers.edu/research-computing/amarel/) | Rutgers' research cluster, free for Rutgers researchers including students | Shared, first-come, first-served access. See [Rutgers tools](rutgers-tools.md#research-computing). |

## Cloud credits

- [Azure for Students](https://azure.microsoft.com/en-us/pricing/offers/ms-azr-0170p): $100 in credit for 12 months, with no card required.
- [GitHub Student Developer Pack](https://education.github.com/pack): partner offers that change over time, sometimes including cloud credits.
