# Learn AI
{: .no_toc }

Courses ordered roughly from no prerequisites to graduate level. All of them are free to watch or read unless noted, and some sell optional certificates.

## No coding required

| Resource | What you'll learn | Good to know |
|:---------|:------------------|:-------------|
| [Neural networks series](https://www.3blue1brown.com/?topic=neural-networks) by 3Blue1Brown | Animated intuition for how neural networks, backpropagation, and transformers work | Short videos. High-school math is enough. |
| [Elements of AI](https://www.elementsofai.com/) by the University of Helsinki | What AI is, what it can and can't do, and how it affects society | Self-paced. *Building AI*, the follow-up course, adds basic Python. |
| [The Ethics of AI](https://ethics-of-ai.mooc.fi/) by the University of Helsinki | Core questions in AI ethics, including responsibility, transparency, rights, and fairness | Self-paced, seven chapters |
| [AI Fluency for Students](https://academy.claude.com/courses/ai-fluency-for-students) by Anthropic | Using AI responsibly for learning, career planning, and coursework | Ends with an assessment and a completion badge. Anthropic suggests taking *AI Fluency: Framework & Foundations* first. |
| [OpenAI Academy](https://academy.openai.com/) | Practical AI skills, including a short *AI for College Students* course | Sign in with a ChatGPT account to enroll. |
| [LinkedIn Learning AI courses](https://it.rutgers.edu/ai/building-ai-skills-with-linkedin-learning/) through Rutgers | AI basics, responsible AI, and prompt writing, curated by Rutgers OIT | Access through Rutgers |

## Hands-on machine learning

| Resource | What you'll learn | Prerequisites |
|:---------|:------------------|:--------------|
| [Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) by Google | Regression, classification, neural networks, embeddings, an intro to LLMs, and ML fairness, with interactive exercises | Comfortable programming (ideally Python), plus algebra and basic statistics. Google suggests short NumPy and pandas tutorials first. |
| [CS50's Introduction to AI with Python](https://cs50.harvard.edu/ai/) by Harvard | Search, logic, probability, optimization, machine learning, neural networks, and language | About a year of Python, or CS50x |
| [Practical Deep Learning for Coders](https://course.fast.ai/) by fast.ai | Training and deploying vision, text, and tabular models, top-down and code-first | About a year of coding, ideally Python |
| [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) by Andrej Karpathy | Building backprop, language models, and a GPT from scratch in code | Solid Python and intro calculus |
| [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | Transformers, tokenizers, fine-tuning, and building demos with the Hugging Face libraries | Good Python. An intro deep learning course helps. |
| [Dive into Deep Learning](https://d2l.ai/) | An interactive textbook that pairs the math with runnable code in PyTorch, JAX, and TensorFlow | Python. The book reviews the math it uses. |

| Course | Topic | What's public |
|:-------|:------|:--------------|
| [MIT 6.S191: Introduction to Deep Learning](https://introtodeeplearning.com/) | Deep learning foundations, generative models, and LLMs | Lectures on YouTube and labs on GitHub, updated each year |

## Using and building with AI tools

| Resource | What you'll learn |
|:---------|:------------------|
| [Anthropic prompt engineering guide](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview) | Writing clear prompts, giving examples, and structuring complex tasks. Most of it applies to any chatbot. |
| [Gemini prompting strategies](https://ai.google.dev/gemini-api/docs/prompting-strategies) by Google | Clear instructions, examples, context, and breaking tasks into steps |
| [Anthropic Academy](https://academy.claude.com/) | Free courses on AI fluency, AI's capabilities and limits, and building with the Claude API |
| [DeepLearning.AI short courses](https://www.deeplearning.ai/courses) | Short courses on prompting, retrieval-augmented generation (RAG), agents, and AI coding tools. Pricing varies by course. |
